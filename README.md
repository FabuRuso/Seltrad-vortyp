# Seltrad-vortyp

### **NOT FINAL PROJECT**
**Console Buffer Rendering** 

Written as the challenge in <12 hours

The main idea - an exploration of low-dependencies `C++` abilities as the Math core

Volumizer and the main file were released as minimal viable implementation

---

Includes standard libs only
- `<math.h>`
- `<stdio.h>`
- `<thread>`
- `<windows.h>` as Console Buffer API

---

### Should be released in future:
- Common thread pool
- Removed container-allocations in raycasting funcs
- Separation of input and output implementations
- Bounding Volume Hierarchy
